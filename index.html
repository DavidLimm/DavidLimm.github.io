David Lima, em poucas linhas

Sou estudante de ADS em Recife e desenvolvo aplicações full stack. No back-end, trabalho com Java e Spring Boot, estruturando APIs REST com Spring Data JPA, PostgreSQL e migrations com Flyway. No front-end, construo interfaces com React.

Containerizo o que construo com Docker e escrevo testes de integração com Testcontainers, rodando contra o mesmo banco de produção — porque código que só funciona na minha máquina ainda não está pronto.

Antes do código veio a contabilidade: sou formado em Ciências Contábeis e, desde 2022, trabalho com a gestão de cerca de 300 contratos. Ainda não tive uma experiência formal como desenvolvedor, mas lido diariamente com regras de negócio, conciliação de dados e investigação de inconsistências — e levo essa visão para o software que construo.

Também estou aprendendo inglês ativamente, porque boa parte da documentação técnica boa é escrita primeiro em inglês — e eu quero ler o original, não a tradução.

API REST para gestão da mocidade da IEAD-PE, com MVP na Área 40 e modelo de dados preparado para as 74 áreas.
