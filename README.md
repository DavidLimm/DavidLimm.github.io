# Portfólio — David Lima

Site de portfólio pessoal hospedado via GitHub Pages.

## O que é

Página estática de apresentação profissional desenvolvida com HTML e CSS puros — sem frameworks ou dependências externas. Reúne uma breve bio, stack tecnológica, projetos em andamento e formas de contato.

## Tecnologias

- HTML5 semântico
- CSS (variáveis, grid, flexbox, animações)
- JavaScript vanilla (scroll reveal, menu mobile, efeito de digitação)
- Google Fonts (Space Grotesk · Inter · JetBrains Mono)

## Seções

| Seção | Conteúdo |
|---|---|
| Hero | Apresentação com efeito de terminal |
| Sobre | Bio e stack (linguagens, frameworks, infra, aprendendo agora) |
| Projetos | Cards com status (privado / em andamento / no GitHub) |
| Contato | E-mail, GitHub e LinkedIn |
